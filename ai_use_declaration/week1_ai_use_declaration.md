# AI Use Declaration — Week 1

**Course:** CPEN 438 — Advanced Computer Architecture  
**Project:** Project 13  
**Team:** Group 1

## AI Tool Used

ChatGPT (OpenAI)

## Purpose of Use

During Week 1, AI was used as a supporting tool for:

- planning the initial project structure;
- organising the GitHub repository;
- drafting the initial project charter;
- drafting the requirements specification;
- assisting with Graphviz syntax for the topology and system architecture diagrams;
- explaining Git and GitHub commands;
- organising notes for the assigned technical-paper review;
- explaining concepts related to the ring and 2D mesh topologies.

## Human Verification

All AI-generated material was reviewed before being added to the project repository.

The group manually checked:

- the connections in the 16-node ring;
- the connections in the 4 × 4 mesh;
- the ring and mesh node counts;
- the topology diagrams generated using Graphviz;
- the theoretical diameter and bisection bandwidth calculations;
- the relevance of the documentation to Project 13.

The technical-paper notes were prepared with reference to the two papers assigned to Project 13.

## AI Use in Implementation

No final simulator implementation has been accepted solely because it was generated by AI.

Any AI-assisted code used later in the project will be reviewed, tested and understood by the group before being included in the final implementation.

## Responsibility

Group 1 accepts responsibility for the correctness of the submitted project, including any material produced with assistance from AI tools.
